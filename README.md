# GR Switch

把理光 GR 拍下的照片，原原本本地带进 iPhone 和 iPad。

**Motivation：原版APP实在是太难用了！**

GR Switch 是一款正在开发的原生 iOS 照片传输应用。它围绕两件事设计：**方便地选择照片，可靠地保存原片**。界面只有「传输」和「设置」两个主要入口，采用系统导航、原生控件与自适应照片网格。

> **当前是开发预览，尚无可安装的正式版本。** 核心逻辑与模拟网络检查已通过；完整 iOS 编译、真实相机配对、图库导入及速度测试尚未完成。

## 可以做什么

- **连接相机**：已编写蓝牙发现/配对、读取 Wi‑Fi 信息与手动 Wi‑Fi 连接流程。
- **挑选照片**：浏览相机中的 JPG，单选或全选，切换 SD 卡与内置存储。
- **保存原片**：直接下载原始 JPG，通过 Apple 照片接口导入，不重新压缩；以保留 EXIF 等文件内信息为目标。
- **整理相册**：保存到系统图库、已有相簿，或新建相簿。
- **继续传输**：暂停、重试和恢复未完成队列；已完整下载的照片可继续尝试保存。
- **管理相机**：保存连接信息、重连、移除本机记录；Wi‑Fi 密码保存在本机钥匙串。

上述功能已有代码实现，但最终可用性需要真机确认。原片保留将以相机源文件与照片图库导出的未修改原片 **SHA-256 一致**作为验收依据。

## 使用流程

安装开发版后，在「设置 → 添加相机」连接相机；在「传输」中选择存储位置和照片，再选择保存相簿并传输原图。首次使用需要允许蓝牙、本地网络和照片图库访问。

传输时请保持相机开启，并尽量让应用留在前台。当前按单张照片恢复：中断的照片会重新下载，已经完整下载的照片会保留。暂不承诺无限后台传输、字节级断点续传或具体传输速度。

## 开始开发

```sh
git clone git@github.com:Yubin-Qin/GR-Switch.git
cd GR-Switch
open GRTransfer.xcodeproj
```

需要完整 Xcode 及支持目标系统的 iOS SDK。App 没有第三方运行时依赖。仓库名称为 **GR Switch**；目前 Xcode 工程、scheme 和 App 显示名沿用 **GRTransfer / GR Transfer**，便于保持已有工程与应用标识稳定。
