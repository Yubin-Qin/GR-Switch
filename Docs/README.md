# 开发文档导航

第一次接手：先读 [交接记录](HANDOFF.md)，再按 [开发指南](DEVELOPMENT.md) 在新 Mac 建立环境。需要了解实现时读 [架构](ARCHITECTURE.md)，连接实机前读 [测试计划](DEVICE_TESTING.md)。

| 文档 | 解决的问题 |
| --- | --- |
| [开发环境与换机](DEVELOPMENT.md) | 如何克隆、配置 Xcode/签名、运行检查、在多台 Mac 之间继续开发 |
| [架构与数据流](ARCHITECTURE.md) | 哪个文件负责什么，原图如何进入图库，恢复机制有哪些边界 |
| [开发交接](HANDOFF.md) | 当前真正验证过什么，下一步做什么，哪些问题需要实测 |
| [真机测试](DEVICE_TESTING.md) | 如何验证 GR4 配对、EXIF、吞吐、断线和布局 |
| [资料来源](REFERENCES.md) | 苹果官方接口、理光用户手册与非官方协议研究的区别 |

更新规则：代码行为变化时更新架构与限制；测试通过后记录日期、环境、命令或设备与结果；未执行的项目保留“待验证”。不要把语法检查、模拟 HTTP 或 macOS 核心测试表述为 iOS / 相机兼容性通过。
